## Problem

`/setup` spent LLM tokens on mechanical template resolution, harness translation, manifest hashing, and instance writes. Upgrades could not re-emit from saved answers without re-interviewing.

## Outcome

Shipped **kit v0.27.0** (commit `90c532f`). Added `skills/setup/bin/emit.sh` and `emit.ps1`, migrated templates to `<!-- BOOTSTRAP[id] -->` and `<!-- IF flag -->` grammar, embedded validated answers in the manifest, added `tests/templates/emit-determinism.sh`, and wired `scripts/self-install.sh` to emit from `fixtures/self-answers.json`. Phase 5 audit needed one fix cycle (installed-skill emit path and doc pointers) before APPROVED.

## Key decisions

- LLM runs Steps 1–3 and writes `orchestration-kit.answers.json`; emit twins perform all writes, prune, verify, and manifest update.
- `emit.sh` requires **`jq`**; `emit.ps1` is the jq-free twin.
- Emitters reduced to caveat-only docs (≤3072 bytes each); translation tables live in scripts.
- Upgrade compares sha256 to manifest; user-modified kit-owned files block without `--force`.

## Pitfalls / lessons

- Goal evaluation cycle 1 surfaced want_* vs is_* flags, foreign manifest entries, and a closed D-6 parity allowlist for dogfood diff.
- Polish items (l/m): dry-run reports `keep` for no-op appends; verify errors sorted in `LC_ALL=C` order.
