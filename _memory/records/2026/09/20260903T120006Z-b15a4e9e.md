## Decision

Rename orchestrator proxy `(context + report)/4` to **`io_est_tokens`** everywhere emitted. Add **`work_est_tokens`** from the agent Footprint (`work_read_chars/4`, integer division) on each OUTCOME line, with optional `--work-chars` override when the report block is stripped.

## Why

Tiering and evaluation-depth decisions were made on a metric that tracked a fraction of subagent spend. Labeling io vs work makes the ledger honest without requiring harness APIs for interactive orchestrator sessions.

## Rejected alternatives

- Rename to a wholly new token name without preserving `est_tokens` substring (would break skill-slimming check (e)).
- Fail `outcome` when Footprint is missing (treated as report-format defect for evaluators, not ledger failure).

## Consequences

Log-spawn twins, feature skill, ORCHESTRATION template, and developer guides document both numbers. Loop drivers may additionally print real CLI `usage:` lines when `LOOP_USAGE_FORMAT` is set; gating the loop on usage remains out of scope.
