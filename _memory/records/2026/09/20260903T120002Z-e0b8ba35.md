## Decision

Goal templates and the feature skill expose `phases.ladder: escalate|auto` with default **`escalate`**. After fix-cycle 3 exhaustion, `escalate` stops and presents the user with “run the continuation ladder” as option 1; `auto` reads `reference/continuation-ladder.md` as today. Loop-created goals set `ladder: auto`.

## Why

Interactive feature work was spending six or more frontier spawns on the continuation ladder before a human saw a stuck task. Defaulting to escalate makes the expensive ladder opt-in per goal.

## Rejected alternatives

- Always auto-enter the continuation ladder (status quo).
- Removing the ladder entirely.

## Consequences

Feature skill and escalation-ladder tests assert the skill reads `phases.ladder` before entering the ladder. Dogfood goals on the token-efficiency roadmap used `ladder: escalate` explicitly.
