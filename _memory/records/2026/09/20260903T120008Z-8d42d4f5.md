## Decision

After the interview, `/setup` writes a schema-1 answers JSON and runs `bin/emit.sh --answers …` (with `--check-answers` to list missing bootstrap ids). The LLM no longer hand-copies templates into `.claude/`, `.cursor/`, etc. Upgrades use `emit.sh --upgrade`, reading embedded manifest `answers` when present.

## Why

Release D of the token-efficiency roadmap targets finding 1: mechanical emit work was the largest avoidable token spend in setup.

## Rejected alternatives

- Python/Node emitter (roadmap chose Bash + pwsh 7 twins only).
- Keeping translation tables in emitter markdown (moved into scripts; emitters are caveats only).

## Consequences

Manifest always rewrites and stores full `answers`. Pre-v0.27.0 installs without manifest answers must pass `--answers` once. Verify pass rejects leftover `{{TOKEN}}`, BOOTSTRAP, and IF markers in written files. Self-install dogfood proves byte parity against a fixture aside from a closed allowlist of known instance artifacts.
