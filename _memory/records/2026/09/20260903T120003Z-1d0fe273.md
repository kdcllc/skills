## Problem

After each subagent spawn the orchestrator hand-wrote ledger entries, computed `context_chars`, `report_chars`, and `est_tokens`, and maintained a running total—clerical work at frontier rates with error-prone arithmetic across 30+ spawns per goal.

## Outcome

Shipped **kit v0.25.0** (commit `d06e9e5`). Added `_kit/log-spawn.sh` and `_kit/log-spawn.ps1` (single-copy emit), rewrote the feature skill orchestration-log section in compact form, updated emitters and docs, re-emitted the instance, and added `tests/templates/log-spawn.sh`. Phase 4 included an inline orchestrator implementation when subagent spawn UI timed out; Phase 5 final audit APPROVED after goal revision.

## Key decisions

- Emitted tools live under `_kit/` (always emitted, harness-agnostic).
- Context packages and verbatim reports are files: `_goals/<goal>/spawns/NN-context.md` and `NN-report.md`; the log references paths instead of inlining bodies.
- CLI subcommands: `spawn`, `outcome`, `note` with frozen exit codes, timestamp format, file-byte counts, floor division for `est_tokens`, and append-only semantics.

## Pitfalls / lessons

- Subagent “timeout waiting for bubble creation” was UI-side only; parallel work reconciled to one green tree.
- Portability freeze (UTF-8 no BOM, `AppendAllText` only in pwsh, check order 2→4→3) had to be spelled out after evaluator NEEDS REVISION.
