## Decision

Whenever the canonical ORCHESTRATION architecture template is corrected to reflect shipped workflow behavior, add or extend standalone structural guards (pattern: `tests/templates/template-currency.sh`) that assert the fixed claims on the template and on emitted instances when present, with SKIP-when-absent — not reliance on manual audits alone.

## Why

The v0.21.0 effort started from an evaluator audit that found six contradictions/omissions between template summary and skills/drivers shipped across eight minor releases.

## Rejected alternatives

- Emitter-only fixes without template updates (insufficient — installs compile from canonical source).
- Copying entire skill sections into ORCHESTRATION (rejected — summary + defer detail).

## Consequences

Future workflow changes that alter summary-level truth must update ORCHESTRATION **and** the currency guard in the same goal. `escalation-ladder.sh` remains the ladder-specific guard; template-currency covers cross-cutting summary drift (research Phase 3 gate, loop dispatch mode, exit funnel, rung-3 timing, merge gate).
