STORY-007 pinned a single normative sentence in the canonical goal-criteria template (`skills/setup/templates/skills/goal-criteria/SKILL.template.md`) about tasks still carrying bracket-literal placeholder values in ownership blocks. The same wording must appear byte-stable on the canonical line and its A4 sibling twin port.

Three consumers depend on that exact text: check K (ownership-contract shape grep in `.claude/checks.sh`), harness assertion 27 in `tests/loop-harness/run.sh` (presence grep for `bracket-literal placeholder values`), and the twin template line. Integrity is verified by hashing the chosen template line with `sed -n 'Np' | sha256sum` including the trailing newline — any re-wrap, re-indent, or reflow breaks downstream checks even if meaning is unchanged.

Never edit that clause casually in later stories; treat it like a shared contract literal.
