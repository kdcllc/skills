## Decision

Amend the canonical **test-ladder** skill so a goal’s **designated closer task** may run **rung 3** when its task file explicitly mandates full suite runs as the story’s closing gate—subject to written mandate, actually-last-task timing, and at most one such task per goal.

## Why

Three stories with two independent judge PASSes established that orchestrator-authored task mandates delegate rung-3 authority, the gate satisfies regression intent, and acceptance criteria like “checks A–K green; harness green” are unsatisfiable at rungs 1–2. Moving suites to an unjudged orchestrator-only run would weaken the kit’s verification invariant.

## Rejected alternatives

- **(b)** Keep the table absolute and route full suites only to orchestrator Phase 5 (would retroactively invalidate judged goal packs and lose judged close evidence).

## Consequences

Phase 5 Quality Checks still runs full suites at cycle end and does not replace closer-task gates. Agent and feature-skill one-liners remain shorthand citing the ladder. task-criteria rationale text about “once at cycle end” is inaccurate under (a) but the do-not-fail-for-skipping rule half remains true.
