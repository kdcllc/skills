STORY-009 hardened `_breaker_write` and initial state validation. The validity pass alone costs on the order of tens of milliseconds (multiple greps and subshell forks in `skills/setup/templates/loop/breaker.sh`). A timing-window test fixture bounded at ~30ms could rewrite the state file **before** the retry loop under test began, masking the race under investigation.

Timing-dependent breaker tests need deterministic hooks (shadowed `sleep` primitive plus call counter), not loose wall-clock bounds. Mutation testing exposed this coin-flip; repeated green runs without mutation would not.
