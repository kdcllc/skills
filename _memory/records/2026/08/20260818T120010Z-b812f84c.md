## Problem

Windows-support and circuit-breaker audits left seven non-blocking defects: emitter invocation inconsistency, contradictory setup guidance, manifest hash drift on runtime files, wrong twin header paths, missing repo `.gitattributes`, PowerShell git/PROMPT edge cases, and a SIGPIPE-exposed sentinel check in bash loop.

## Outcome

Shipped kit v0.7.0 (commit caa3548, eleven-path explicit staging). Applied emitter, setup manifest, loop twin header, loop.ps1, loop.sh sentinel, and harness updates; root `.gitattributes` with LF for `*.sh` and `*.ps1`. Combined Phase 6 doc alignment with story-004 (commit 5a1ff10). Harness reached 30/30 assertions. Backlog STORY-006 passes: true. Human-orchestrator execution only (CB0-protected paths).

## Key decisions

- A2: drop OS-gated checks-script guidance; adoption of a checks script alone triggers PowerShell twin guidance (matches no OS-detection emit doctrine).
- A3: `seedFiles` lists only `_goals/backlog.md`; LEARNINGS, ESCALATIONS, and breaker state are unmanaged runtime paths with no manifest hash.
- A4: parity headers reference sibling twins in `_loop/`, not canonical template paths absent in installs.
- T1b: coalesce only null `Get-Content` results for empty PROMPT.md, not whitespace-only files.

## Pitfalls / lessons

- Check J could not be authored in the same story that defines seed semantics (deferred to STORY-007).
- pwsh runtime verification debt for T1a/T1b remained skip-aware on Linux dev boxes.
- Manifest hash refresh must join `files` with `seedFiles`; naive iteration misreports seed drift.
