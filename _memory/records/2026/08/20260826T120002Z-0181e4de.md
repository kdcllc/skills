## Problem

The feature skill grew to ~16 KB with heavy mandatory reads (full ORCHESTRATION template, per-task contract gate adding two spawns per task), always-on Phases 6–7, template skill copies leaking into harness discovery, and no spawn cost visibility.

## Outcome

Shipped kit **v0.23.0** (release commit `92e6968`). **Contract gate removed**: acceptance criteria with verification methods live in task files at Phase 2; Phase 3 goal evaluator validates once; `contract.md` and `contracts/` flow deleted. Continuation ladder moved to `reference/continuation-ladder.md` (loaded on cycle-3 exhaustion only). Canonical skills renamed **`SKILL.template.md`** with emitters mapping to `SKILL.md` so `{{PROJECT_NAME}}` copies stop polluting discovery. Optional Phases 6/7 via `phases:` block in `goal.md` (interactive + loop docs). Orchestration-log proxy metrics: `context_chars`, `report_chars`, `est_tokens` per spawn. Eight tasks PASS; Phase 5 audit APPROVED after docs link sweep; ~91k proxy est_tokens logged. Phase 7 user-gated on master with mixed uncommitted template-currency tree.

## Key decisions

- Ownership blocks (`writes`/`reads`/etc.) unchanged — only sign-off contract flow removed.
- Preserve template-currency in-flight ORCHESTRATION mermaid (G7 byte-identical with feature-workflow guide).
- `align_docs` and `pull_request` both true for this goal — docs were core deliverable.

## Pitfalls / lessons

- Final audit caught stale "signed contract" prose and `templates/**/SKILL.md` links in docs/guide — required fence amendment on task 07.
