STORY-009's fail-safe inversion includes mechanism B: loading a corrupt breaker state file can sleep a full cooldown at loop startup before retries engage. That behavior spans the loop driver and `_loop/breaker.sh`, not an isolated function unit.

Function-level breaker tests correctly omit this; a driver-level test belongs with STORY-011's driver-owned breaker integration when the loop owns breaker lifecycle end-to-end.
