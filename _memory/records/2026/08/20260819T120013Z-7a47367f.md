Tasks that write gitignored instance paths (for example under `.claude/` or manifest-backed instance files) leave no trace in `git status`. Fence verification cannot rely on tracked diff alone.

The adopted pattern compares manifest `files` map hashes before and after execution, or uses an mtime window when hash evidence is impractical — now codified in task acceptance criteria for gitignored write-sets.
