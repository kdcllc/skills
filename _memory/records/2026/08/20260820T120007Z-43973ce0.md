## Decision

All run-terminal paths except CB0 **exit 4** and loud **exit 5** stops route through one driver function that evaluates, top-down: all slots retired with any CB2 reason → **3**; all retired all CB1 → **2**; max-iter with eligible stories or drained with quarantined branches → **1**; drained clean → **0**. CB1/CB2 at reap **retire** slots (no refill) instead of `exit 2`/`exit 3` immediately.

## Why

Independent terminal gates allowed a slot retiring on the same dispatch that exhausted MAX_ITER to report success while CB retirement semantics demanded 2 or 3. §7.3 “no slot made progress” is read as “every slot retired” so N=1 behavior matches prior CB codes on every route.

## Rejected alternatives

- Separate in-loop and bottom gates without shared funnel (proved escape to lying 0/1).
- Keep run-fatal CB exits at reap (blocks productive multi-slot runs).

## Consequences

MAX_ITER exhausted with genuinely drained backlog and no quarantine now exits **0** (intentional N=1 change). Completion banners print on funnel outcomes, not unconditionally before aggregation. P1 contract block documents driver-aggregated semantics in both twins.
