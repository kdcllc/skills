## Decision

Add check K distinct from J: verify canonical task template carries five ownership fields once each, worker agent templates contain the literal `Write fence`, and goal-criteria template includes the Ownership contract heading plus pristine-block clause—canonical side only, not instance twins.

## Why

STORY-008 introduced plan-time contracts; without a structural tripwire, a future edit could drop fields silently. Check G is content-based and cannot catch header path or block-shape regressions.

## Rejected alternatives

- Extend check B/D to cover instance ownership blocks (they grep tokens and frontmatter names only—accepted gap this story).
- Merge K into J (different concerns: manifest hashes versus template shape).

## Consequences

Instance re-emit fidelity still relies on supervised emit plus spot checks. Later addenda extend K for PRISTINE block rejection and ownership-block structural rules.
