STORY-008's ownership block includes a `depends_on:` field listing task ids that must land before another task runs. When two tasks declare overlapping paths in `writes:`, disjointness checking normally fails — unless a `depends_on` edge exempts the pair.

That exemption is only valid when there is a genuine produce-then-consume handoff (upstream task emits an artifact the downstream task reads). Evaluators must ask whether the edge reflects real data flow, not a convenience link added to legalize concurrent writers on the same file.
