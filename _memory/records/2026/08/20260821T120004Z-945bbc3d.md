## Decision

The Cursor emitter unconditionally materializes skills, ORCHESTRATION.md, and the model map under `.cursor/`, resolving every `{{IDE_DIR}}` to `.cursor`. It must not skip those rows when `.claude/` already exists. Rules and agent path references in Cursor surfaces cite `.cursor/` only.

## Why

Cursor was silently following `.claude/` instructions and model pins, breaking the user's requirement that Cursor sessions use Cursor models and paths only.

## Rejected alternatives

- Hand-patch dogfood instances without emitter fixes (forbidden — canonical-first).
- Copilot self-containment in the same release (deferred).

## Consequences

Dual installs carry duplicated skill trees by design. Re-run `/setup` migrates pre-v0.19.0 reuse layouts. Loop drivers still single-copy `_loop/*` to the primary harness; extending circuit-breaker protected paths to `.cursor/**` remains follow-up work.
