## Question

How to cut session token cost without weakening judges, fresh-context workers, or Cursor `.mdc` rules?

## Load-bearing findings

- Session start loads skill name+description only (~500–900 tokens for nine skills); main cost is auto-fire and double-loading, not description size.
- `disable-model-invocation: true` shared across Claude Code, Cursor, Copilot; seven of nine kit skills flagged via `_goals/invocation-flag-hygiene/`; `feature` and `research` stay auto-invocable by design.
- Light `terminal` agent (Bash+Read, compact return) shipped on Claude/Cursor/Copilot plus Codex registration; rung 3 full suite via terminal spawn.
- Copilot cost ceiling blocks pinning up, not down—frontier parent + light terminal/workers; do not weaken frontier evaluators to save tokens.
- Harness-matrix addendum 2026-08-20 is emitter source of truth for capability cells from this research.

## Decisions taken

- P0 invocation flags and P1 terminal agent shipped through invocation-flag-hygiene goal; reference/ demotion and quiet-command setup interview remain future work.
- test-ladder: disable auto-invoke but keep explicit context-package cites.

## Open questions

- Further skill description tightening; optional reference/ demotion for large criteria skills.

## Where it shipped

P0/P1 via `_goals/invocation-flag-hygiene/` (terminal agent aligns with kit v0.15.0+ terminal work in release history); harness-matrix addendum dated 2026-08-20 in repo.
