## Decision

Kit-repo-only **`scripts/self-install.*`** twins install top-level skills by **full tree copy** into `.claude/skills/<name>/` and `.cursor/skills/<name>/` (optional **`--symlink`** through `.agents/skills/`). Any failure exits non-zero after restoring prior dest state; no partial success surfaces.

## Why

Dogfood needs offline, reproducible skill surfaces matching the skills.sh client layout without invoking npx or coupling to `/setup` emit. Independent full trees avoid symlink write-through surprises in harness dest checks unless `--symlink` is explicitly requested.

## Rejected alternatives

- Emit self-install via setup templates to consumers (explicitly out of v1 scope).
- Silent fallback from failed symlink to copy (forbidden—must fail loud).

## Consequences

Harness self-install block runs before `_loop/` missing guard so assertions execute in fresh clones. README documents copy vs symlink, gitignored dests, and that `/setup` remains the compile step.
