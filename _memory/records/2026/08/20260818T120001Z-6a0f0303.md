## Decision

For Cursor empirical probes, emit both the raw `.claude/` agent tree and separate `.cursor/agents/*-cursor` translated copies with non-conflicting names, instead of relying on a single emission path.

## Why

`.cursor/`-wins shadowing could mask raw-tree frontmatter behavior. The emitter live-schema check is skipped because the documented schema is the hypothesis under test. Nonces and decoy controls require knowing which tree each probe exercised.

## Rejected alternatives

- Single-path emission per standard emitter instructions (risk of shadowing invalidating Q1 raw-tree claims).
- Skipping the Cursor arm entirely when `cursor-agent models` is empty (replaced by honest untestable cells plus minimum-evidence floor escalation).

## Consequences

Probe fixtures are heavier to bootstrap but answer raw-tree fidelity (Q1) and cursor-schema acceptance (Q2) in one budget. Results must label which tree each cell references. GUI and Codex CLI behavior remain explicitly untested in this story.
