Unlike bash `set -e`, PowerShell does not abort the script when a native executable such as `git` returns non-zero. On the `_loop/loop.ps1` driver path, every native git invocation needs an explicit `$LASTEXITCODE` check (or equivalent) before continuing.

An ungated `git worktree add` failure in STORY-010 would have misdiagnosed later checks and, on rerun, could force-delete a retained quarantine branch — caught by the evaluator (then called the judge).
