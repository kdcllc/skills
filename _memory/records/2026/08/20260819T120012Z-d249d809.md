Each task's ownership block includes `owner:` (implementer or test-writer — single writer per task). The orchestration log records which agent type was actually spawned. Until STORY-007 addendum 4 adds an automated structural owner check, goal judges should cross-check those two sources manually.

A mismatch means the wrong worker class executed a fenced write-set, breaking the single-writer assumption ownership contracts depend on.
