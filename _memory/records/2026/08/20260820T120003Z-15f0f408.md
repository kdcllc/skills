## Decision

Ship slot supervision structure with **LOOP_SLOTS** read and clamped [1,3] but forced to **effective 1** when greater than 1 (warning only if explicitly set above 1). **LOOP_WORKTREE** defaults **0** so default runs stay main-tree equivalent; `=1` enables worktrees with loud tracked-instance preflight and exit **5** on failure—never silent fallback.

## Why

Without STORY-011’s claim table and integrator, concurrent slots would duplicate story selection (design’s guaranteed outcome). Worktree execution is inoperable when the agent instance directory is gitignored. Staging structure before dispatch avoids a double-sized STORY-011.

## Rejected alternatives

- Enable N=2 immediately with worktrees (empirically broken in this repo; admission forbids concurrent duplicate writes today).
- Byte-identical output to pre-story driver (impossible once slot banner prints; replaced by enumerated behavior-equivalent contract).

## Consequences

STORY-011 removes the slot clamp and activates N>1 when worktree isolation is on. Real dogfood runs here stay serial until tracked instances use worktrees.
