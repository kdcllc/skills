## Problem

Contributors dogfooding this kit had no tracked, offline way to install the skills.sh **client surface** (top-level `skills/<name>/` trees) into `.claude/skills/` and `.cursor/skills/` without npx, network, or an agent session—separate from `/setup` compilation of agents, `_loop/`, and manifest.

## Outcome

Delivered **`scripts/self-install.sh`** and **`scripts/self-install.ps1`**: copy every top-level `skills/*/SKILL.md` tree to both harness dirs (optional **`--symlink`** via `.agents/skills/` hub), strict fail-fast with snapshot rollback, flags `--dry-run`, `--force`; **`.gitignore`** entries for `.cursor/skills/` and `.agents/skills/`; README self-install section; loop harness assertions **69–85** (with SKIP-aware `report()`) using throwaway fixture repos only. Phase 5 audit APPROVED; Phase 6 README and design-doc citation fixes APPROVED. No kit VERSION bump in this goal (repo tooling, not a semver feature release).

## Key decisions

- Dest success = byte-identical copies from working tree source; do not claim parity with live npx flag sets.
- Write order `.claude` then `.cursor` with restore on partial failure; overwrite via remove-then-create.
- Tests never use live gitignored dest dirs as the sole proof substrate.

## Pitfalls / lessons

- Early task 05 tried to SKIP pwsh rows incorrectly until harness `report()` gained SKIP support.
- Rollback tests must pre-seed bytes on the skill name actually installed first to avoid vacuous passes.
