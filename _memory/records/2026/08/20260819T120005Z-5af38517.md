## Decision

Map the conflict-free multi-agent research drop-in checklists to kit phases: task-file declaration rules live in goal-criteria (Phase 3 task decomposition review); execution-only fence compliance lives in task-criteria (Phase 4), including verifying the context package carried the write fence matching orchestration-log claims.

## Why

In this kit, Phase 3 judges task definitions before execution; Phase 4 judges completed work. The research doc’s task-criteria additions mix declaration and execution checks that must split to avoid judging fences before tasks exist.

## Rejected alternatives

- Literal paste of all items into task-criteria only (would not catch bad plans pre-execution).
- Literal paste into goal-criteria only (would miss delivery-time out-of-fence edits).

## Consequences

Goal judges enforce DAG, disjoint writes, and contract freeze rules. Task judges enforce scope discipline with orchestrator fault routing when context packages omit fences. Criteria template wording must stay traceable without embedding docs citations into canonical product files against isolation rules.
