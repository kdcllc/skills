Check G in `.claude/checks.sh` is a parity drift tripwire: both canonical loop twins must contain the sentinel string, exit codes 0–5 as literal `exit N` patterns, and matching default iteration counts — not merely equivalent control flow.

Refactoring bash or PowerShell drivers to `exit "$var"` can remove the literal `exit N` tokens G searches for. STORY-010's exit-deferral change failed G on the new file while the unmodified twin still looked compliant. Any exit-path refactor must preserve tripwire-visible literals or update check G and both twins together.
