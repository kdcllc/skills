## Decision

Migrate `judge` / `qa-judge` to `evaluator` / `qa-evaluator` in one release with no deprecated stub files. Setup upgrade flow must **prune stale emitted files** (manifest keys absent from the new emit set are removed). Every install re-emits so old agent filenames cannot coexist with new ones.

## Why

Alias shims were unverified in Cursor picker and Copilot dual-tree dedup — they risked duplicate or wrong subagent selection.

## Rejected alternatives

- Long-lived deprecated `judge.md` copies beside evaluators.
- Renaming verdict tokens or exit codes (frozen).

## Consequences

Emitters and setup SKILL must document the v0.18.0 prune case without judge-family words in live prose. Future role renames should plan manifest key migration and instance re-emit the same way. Frozen historical comments in loop templates and old test provenance lines remain exempt from vocabulary sweeps.
