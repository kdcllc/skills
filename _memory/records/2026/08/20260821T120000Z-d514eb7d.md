## Problem

Canonical `loop.ps1` used `"$Slot:"` inside double-quoted strings at four sites. PowerShell treats `$Slot:` as an invalid scope qualifier, so the driver failed to parse on Windows hosts and check F (pwsh parse) failed wherever pwsh was installed—masked on hosts without pwsh.

## Outcome

Fixed by changing each site to **`${Slot}:`** in the canonical template on branch worktree **fix/loop-ps1-slot-interpolation** (commit **b565651** on that branch), merged to master as **5825729** via stash/merge/pop preserving parallel v0.19.0 comment hunks. Task 02 added a structural regression tripwire in instance **checks** twins (check L pattern for `"$Identifier:"` in scoped PowerShell templates). **No kit VERSION bump** (bugfix; v0.19.0 feature owned the next version). No pull request—local merge per user choice.
