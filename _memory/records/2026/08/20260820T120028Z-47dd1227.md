`git worktree add` checks out **tracked** files only. In a self-install instance where `.claude/`, `.cursor/`, and `_loop/` are gitignored, worktree-based iteration cannot see the emitted harness tree — worktree execution is inoperable without a separate materialization step.

STORY-010 shipped `LOOP_WORKTREE` as opt-in default 0, with preflight requiring a backlog FILE path plus `{{IDE_DIR}}` DIRECTORY existence (the skill-file path prescription is Claude Code–specific; goal judgment corrected over-broad wording).
