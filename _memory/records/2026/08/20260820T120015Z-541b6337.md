## Decision

Skills that must not be model-chosen (`align-docs`, `ship-pr`, `auto-loop`, the three `*-criteria` skills, and `test-ladder` with `user-invocable: true`) carry `disable-model-invocation: true`. The orchestrator loads them only via documented explicit sites: path-Read for Phase 6/7 skills, and a leading `/auto-loop` line on the loop prompt — not via ambient skill discovery.

## Why

Auto-discovery injected orchestration skills into every session and allowed workers to invoke delivery or loop drivers out of phase order.

## Rejected alternatives

- Demote those skills to `{{IDE_DIR}}/reference/` (deferred).
- Rely on model-emitted `/skill` names inside `feature` as a bypass (explicitly rejected in goal judgment).

## Consequences

Emitters must preserve the frontmatter flag. New phase-gated skills need the same pattern plus an orchestrator call site in templates. `test-ladder` keeps dual flags (`user-invocable` + disable) so humans can still invoke it manually.
