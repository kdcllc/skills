## Decision

Extend `orchestration-kit.manifest.json` with a top-level `seedFiles` array containing only `_goals/backlog.md`. Record emit-time hash but exempt seeds from upgrade diff-confirm overwrite. Classify LEARNINGS, ESCALATIONS, and breaker state as unmanaged—not in `files` or `seedFiles`.

## Why

Runtime-mutable goal artifacts caused guaranteed hash drift when treated as managed emissions. Only backlog is actually emitted as create-if-missing seed content.

## Rejected alternatives

- Listing LEARNINGS or breaker state in `seedFiles` (not emitted or gitignored runtime scratch).
- Null-hash sentinel in manifest schema (open question deferred; two-structure join chosen for check J later).

## Consequences

Setup Step 5 documents create-if-missing for seeds; emitter tables note backlog never auto-overwrites. Check J must join `files` minus `seedFiles` for integrity enforcement (STORY-007).
