Goal judges and coverage checks need an intended-change set that is independent of how tasks happen to be written. If that set is inferred only from the Tasks table, the ownership coverage check becomes a tautology: the plan defines both the claimed paths and the checklist that verifies them.

After STORY-008 (plan-time ownership contracts), the normative source for what the goal may touch is Success Criteria plus Out of Scope in the goal pack. Task-level `writes:` fences describe per-task authority, not the goal-level intent surface.
