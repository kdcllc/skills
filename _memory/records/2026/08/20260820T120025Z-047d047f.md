The tracked repo keeps canonical templates under `skills/setup/templates/` while self-install emits `_loop/` twins. Harness assertions that read `_loop/` before the story's re-emit task runs see stale instance copies — the instance-lags-canonical seam.

STORY-009 hit this twice: assertion 18's mutation-proof against `_loop/loop.ps1`, and other assertions assuming refreshed `_loop` after task 04's emit. Mitigation: pin each assertion's extraction source explicitly in the harness story, and escalate when a fix would require editing out-of-fence paths instead of adjusting pins or emit ordering.
