When a task's write-set includes gitignored instance files tracked only via `orchestration-kit.manifest.json`, executors must record the manifest hash (or per-path hashes) **before** mutation, not only verify afterward.

Judges can then confirm the fence from logged pre-image to post-image. STORY-007 task 04 established this as explicit policy after earlier runs accidentally demonstrated good practice without stating it as a rule.
