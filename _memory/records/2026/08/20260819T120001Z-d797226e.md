## Decision

Check J recomputes manifest hashes for all managed `files` entries except `.claude/checks.sh`, reporting that path as self-excluded, mirroring check B’s self-exclusion precedent.

## Why

This story edits checks.sh before task 04 refreshes the manifest hash. Enforcing J on the checker’s own entry creates an unsatisfiable sequencing deadlock.

## Rejected alternatives

- Refresh manifest before editing checks (still races mid-story edits).
- Extract check J to a separate file in this story (scope creep).

## Consequences

J never guards checks.sh content; manifest record still updated on emit. Mutation tests must cover naive seed verifier failure modes separately.
