## Decision

Under `skills/setup/templates/`, orchestration skill sources use the filename **`SKILL.template.md`**. Emitters map each to harness-local `SKILL.md` on install. No bare `SKILL.md` remains in the canonical template tree.

## Why

Emitted copies with substituted `{{PROJECT_NAME}}` were being discovered as live skills in harness skill lists, double-charging context and leaking placeholder vocabulary into discovery.

## Rejected alternatives

- Rely on harness-specific ignore rules per IDE (less portable than emitter rename).
- Inline all skills into ORCHESTRATION (rejected — maintain separation).

## Consequences

All four emitters need explicit template→destination rows for `SKILL.template.md`. Tests and docs that linked `templates/**/SKILL.md` must retarget template paths or emitted destinations. Instance trees keep `SKILL.md` names post-emit.
