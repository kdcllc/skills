The orchestration kit manifest file is gitignored on self-install instances. Check J in `.claude/checks.sh` recomputes sha256 for entries in the manifest's `files` map (with `seedFiles` exempt) and enforces `kitVersion` equals `skills/setup/VERSION`. It does **not** baseline metadata fields such as `installedAt`, `harnesses`, `options`, or top-level `seedFiles` structure beyond the hash join.

Whenever a task's write-set includes the manifest, perform a semantic audit: kit name, harness list, and options should match reality even when J is green on file hashes alone.
