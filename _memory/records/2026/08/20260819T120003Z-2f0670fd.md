## Problem

Multiple features or tasks could claim the same write paths because task files listed files in prose only, criteria lacked disjointness checks, and worker agents had soft scope guidance without fail-loud fences—inviting merge-time repair instead of plan-time prevention.

## Outcome

Shipped kit v0.8.0 (commit 9e57310, eleven explicit paths, co-dispatch warning in commit message). Canonical task template gained machine-readable ownership blocks; goal and task criteria gained contract checklists; implementer and test-writer templates gained write fences with escalation; feature skill injects per-task writes into context packages. Supervised instance re-emit refreshed manifest hashes. Aligns with design-parallel-dispatch plan-layer admission; driver-side admission left to STORY-011.

## Key decisions

- Bracketed placeholder guidance in templates, not BOOTSTRAP comments, so emitted instances pass check B.
- Re-map research drop-in lists: declaration checks to goal-criteria Phase 3; execution fence checks to task-criteria Phase 4 with delivery cross-check for context packages.
- Goal-criteria ownership dimension adds six checks (coverage, disjointness, single owner, DAG, freeze-before-consumers, hotspot rule) without changing dimension count semantics.
- Supervised execution only—CB0 paths (.claude agents/skills, manifest) cannot be touched by unattended loop iterations.

## Pitfalls / lessons

- Initial goal pack contradicted itself on canonical file count versus eight changed templates.
- Dogfood task files used quoted depends_on ids—the fix task 02 ships.
- Commit message must warn about co-dispatch when plan contracts and runtime stories overlap.
