## Decision

After Phase 5 audit APPROVED, rung 3 of the test ladder is orchestrator-authorized but orchestrator-**executed** by spawning the light-tier `terminal` agent. The orchestrator does not run `{{FULL_TEST_COMMAND}}` in its own session. On non-zero exit with truncation, the orchestrator Reads the log path (bounded slice) and may re-spawn `terminal` with a narrower command — never re-dumps the full suite into the frontier context.

## Why

Full test and build output dominated orchestrator context on `/feature`, especially on Copilot where output caps are weaker.

## Rejected alternatives

- Enable Copilot nested subagents so workers spawn `terminal` (kit default stays off; L1 orchestrator spawns).
- Hooks or global quiet flags in templates (out of scope for this goal).

## Consequences

`test-ladder` and `feature` skills document the authority vs execution split. Canonical `terminal.md` stays edit-free (`Bash, Read` only). Closer-task carve-out: a fenceless `terminal` reporter is not a designated closer task.
