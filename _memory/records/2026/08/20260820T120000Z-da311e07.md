**Intent**: Learn how to pick up new or edited Cursor Agent skills without restarting the whole IDE.

**Decisions**: Treat starting a **new Agent chat** as the primary way to refresh the skill catalog (names, descriptions, and slash autocomplete). Use **Developer: Reload Window** only if a new chat still omits a skill from `/` completion. When editing an existing skill file, rely on the agent re-reading `SKILL.md` on invocation rather than expecting catalog metadata to update mid-conversation. No in-chat hot-reload command exists yet (tracked as a product gap).

**Outcome**: Documented the current Cursor behavior: skill lists are snapshotted per chat; full skill names can often still be typed manually when autocomplete lags; catalog metadata is stable within a session while file contents can be refreshed on use.

**Open threads**: Whether Cursor will ship an explicit skill reload command; no repo changes were requested or made.
