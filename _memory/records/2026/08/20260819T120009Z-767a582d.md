Goal packs authored before kit v0.8.0 lack the fenced yaml ownership block STORY-008 added to the task template. When such a pack is judged under the new goal-criteria rules, check K (ownership-contract shape on canonical templates) and the goal judge's missing-block remedy apply fail-closed: the orchestrator must author the ownership block from the current task template and re-judge.

That remediation is template backfill, not a failed decomposition cycle — it does not count toward limits on re-decomposing tasks.
