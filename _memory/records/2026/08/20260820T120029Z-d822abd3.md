Success criteria demanding byte-identical loop driver output become untestable the moment any new banner, slot table line, or warning string ships — even when user-visible behavior is unchanged.

STORY-010 replaced byte-equivalence with an enumerated behavior contract that `tests/loop-harness/run.sh` asserts item-by-item (dark-launch slot counts, preflight gates, exit semantics). New output must extend that contract explicitly rather than claiming full file equality.
