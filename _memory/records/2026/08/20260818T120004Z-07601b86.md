## Decision

Persist model circuit breaker JSON state at `_goals/breaker-state.json` and forbid staging it in loop commit guidance, rather than placing state under `_loop/` or other CB0-protected paths.

## Why

Protected-path commit sweeps exit 4 when `_loop/` changes. Runtime breaker state must survive iterations without tripping CB0 or being treated as a managed manifest emission.

## Rejected alternatives

- State file inside `_loop/` (blocked by CB0 semantics).
- Treating breaker state as a seeded manifest file (runtime mutable; not emitted by setup).

## Consequences

Setup skill must append `_goals/breaker-state.json` to project `.gitignore` on emit. Manifest and seed-class rules classify breaker state as unmanaged runtime data in later polish work.
