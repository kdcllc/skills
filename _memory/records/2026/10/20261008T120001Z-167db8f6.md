## Decision

Introduce **`MODEL_FAST`** (and per-harness fast model in answers `models.<harness>.fast`). The **terminal** agent emits the fast ID when present; when `fast` is absent, emit uses the **light** model so v0.28.0 byte-identical output is preserved for other roles.

## Why

Anthropic positioned Haiku 5.5 for subagent work; terminal runs are narrow command execution and should not consume light/standard-tier quota when a cheaper tier exists.

## Rejected alternatives

- Mandatory fast field in answers schema (would break existing fixtures until re-interviewed).

## Consequences

Placeholder table and emit derivation add fast alongside frontier/light/alt_family. Docs and agents-and-models guide describe three tiers. Dogfood fixture pins Claude Haiku 5.5 and keeps Cursor terminal on Composer fast tier.
