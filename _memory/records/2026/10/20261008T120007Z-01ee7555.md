## Question

- Claude Code: alias resolution provider-dependent; cannot run non-Anthropic models natively—cross-family arbiter needs external CLI route; headless `-p` Fable billing risk for loops.
- Cursor: bracket frontmatter params documented; silent fallback to parent model when subagent model unavailable; `agent models` may return empty on some accounts.
- Role map: frontier for orchestrator, evaluator, qa-evaluator, diagnostician; standard for implementer/test-writer; Haiku 5.5 evidenced for fast/`terminal`; read-only via harness enforcement not model obedience.

## Decisions taken
