## What changed

- Ledger: `LOOP_LEDGER` (default on, `$PWD/_memory/loop/ledger.jsonl`, `off` disables, custom path allowed), one JSON line per reaped or killed slot with a frozen key list; stderr run summary after at least one reap, never in `--lint` mode. Emit adds the ledger to loop installs' `.gitignore`.
- Opt-in limits: `LOOP_ITER_TIMEOUT` (timeout/gtimeout `-s INT -k 60`, hybrid detection: 124/137 always, other nonzero only if elapsed >= N and no rate limit), run/story token and USD budgets (run budget stops claiming, exit 1; story budget blocks plus an ESCALATIONS entry; fail open without usage), `LOOP_ITER_BUDGET_USD` (Claude only).
- `LOOP_TAMPER_CHECK` warn (default) / fail (worktree only, quarantine reason `tamper`) / off, signals deleted/skip-marker/assertions-removed, `LOOP_TEST_PATTERNS` override.
- `loop.sh --lint [path]`: shares the driver parser via a lint mode of `_loop_parse_backlog`; exit 0/1/5; no side effects; integers must be decimal without leading zeros.
- One setup-failure helper `_loop_setup_fail` (sixth `exit 5`; harness assertion 96 now 6/5). loop.ps1/breaker.ps1 frozen at 1.1.2 (header comments only). Templates, guide, README and CHANGELOG updated; new suite tests/agent-kit/templates/loop-guards.sh (19 cases, mutation-proven); 82 goldens regenerated.
