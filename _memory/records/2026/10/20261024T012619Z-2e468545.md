## Decision

Retry context and rate-limit recovery in the agent-kit bash loop driver work as follows.
- **Retry dossier:** the driver writes a per-story attempt dossier, on by default, to a gitignored store. It combines driver facts (outcome, exit status, tamper reasons, failure signature, diffstat) with an optional slot file `<outbox>/attempt.md` (headings `## Verdict`, `## Unmet criteria`, `## Failing tests`, `## Notes`). It is appended to the next prompt as a fenced DATA block.
- **Breaker recovery:** the model breaker recovers upward through a scheduled probe of the preferred model (1800 s after a fallback, doubling, 4 h cap). A failed probe **restores the pre-probe model** rather than stepping down from the preferred one.
- **Structured rate-limit detection:** it lives in an opt-in usage format, `LOOP_USAGE_FORMAT=claude-stream`. `auto` never resolves to it.
- **Text fallback:** that format's fallback is narrowed to stderr plus the final result envelope.
- **Scope:** all of this is bash-only; `loop.ps1` and `breaker.ps1` stay frozen at 1.1.2.

## Alternatives considered

- **Dossier injected by template placeholder** instead of appended: rejected, because it would change `PROMPT.md` substitution points and the dispatch-window pin.
- **Dossier in the tracked tree:** rejected; it's runtime state, so it's gitignored like the ledger.
- **On a failed probe, advance one step from chain[0]:** rejected by the user, because it could land on a model worse than the one in use.
- **Make stream-json the default Claude path:** rejected, because it changes output parsing for every Claude user. Opt-in instead.
- **Unrestricted text fallback over the whole stream:** rejected, because tool output that mentions "rate limit" would trip the breaker.
- **A one-entry chain that never probes:** accepted as today's behavior.

## Rationale

The research found that retry gains come from grounded feedback, not more attempts, and that a breaker which only degrades strands long runs on cheap models.

## Consequences

- The breaker state file has 13 keys. The PowerShell twin drops the four probe keys on rewrite.
- Every doc and template marks these features bash-only. The audit caught one template that didn't, which became corrective task 07a.
- The value name `claude-stream` collides with the repo's model-ID guards, so check E and escalation-ladder check 5 exempt that exact token.
