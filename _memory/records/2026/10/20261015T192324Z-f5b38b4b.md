## Decision

Research studies are stored inside the memory tree. Curated briefs and their index live in a new tracked folder, `_memory/research/` (`<topic>.md` plus `README.md`). Raw scratch stays gitignored in `_memory/work/research/<topic>/` (`prompt.md`, `report.md`, `recalled-memory.md`, `review.md`, `ingested`). The path is fixed like every other `_memory/` path; there is no placeholder and no emitter change.

Briefs carry frontmatter: title, topic (equals the file stem), date, status (proposed, ingested, adopted, shipped, superseded, rejected), optional recheck_by and shipped_in, goals, supersedes, memory (research-ingest ids).

## Why

The user asked for research to live in `_memory/`. Briefs are too large for the 4096-byte record body and must stay mutable as their status changes, so they are not records. The `memory.sh check` gate and the task-criteria tripwire only guard `records/` and `quarantine/`, so editing briefs is safe. Search finds a study through its research-ingest record, whose source is now the brief path.

## Ownership

Only the orchestrator writes `_memory/research/`: research Promote writes `status: ingested` and the index row, research Phase 4 adds the goal and sets `adopted`, and the feature archive sets `shipped`. Workers and driver-dispatched loop slots never write it. goal-criteria flags a task whose `writes:` includes it, unless goal.md records a one-time migration exception.

- research-designing-conflict-free-multi-agents.md moved to _memory/research/conflict-free-multi-agents.md.
- Deleted: research-harness-design-upgrade.md (folded into guides), design-parallel-dispatch.md (shipped parts in guide autonomous-loop.md), docs/agent-kit/ORCHESTRATION.md (replaced by the hub docs/agent-kit/README.md).

## Rejected alternatives

- Briefs under docs/ with a `{{RESEARCH_DIR}}` placeholder: the user chose `_memory/`.
- Committing raw reports: the user kept them as scratch.
- Briefs as immutable records: too large, and their status must change.
