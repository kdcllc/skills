Pitfall: a subagent's verbatim report can be lost when the orchestrator's context is summarized before the report is written to spawns/NN-report.md.

Seen in goal safety-hardening: an implementer fix-cycle return (spawn 16) was only in the conversation when the context was compacted, so the report file had to be reconstructed from the summary. It was logged as reconstructed, and the evaluator accepted it only because independent orchestrator evidence covered every claim.

How to avoid: save the verbatim report and log the outcome in the very next step after a subagent returns, before any verification commands or other spawns. If it is lost anyway, say so in the report file and the outcome note, and back every claim with fresh evidence instead of trusting the summary.
