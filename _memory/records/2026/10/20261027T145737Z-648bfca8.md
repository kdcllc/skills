Goal retire-pwsh-2.0 (agent-kit 2.0.0): shipped on branch feat/retire-pwsh-2.0, uncommitted for review.

Outcome: agent-kit scripts are Bash-only. templates/loop/loop.ps1, templates/loop/breaker.ps1 and templates/tools/memory.ps1 are deleted; bin/emit.sh no longer emits any .ps1, no longer runs the pwsh parse-check verify step, and no longer plans `*.ps1 text eol=lf` for new installs (existing lines are left alone — not added to RETIRED_GA_LINES). Loop-enabled installs get `_loop/loop.cmd`, a byte copy of templates/tools/bash-launcher.cmd (CRLF preserved via tpl_bytes_into). Upgrades prune unmodified .ps1 files through the existing manifest pruning (real 1.1.3 install: pruned 3, warnings 0); modified copies are kept with a warning. Every twin / "frozen at 1.1.2" / "bash-only" / "bash driver" qualifier was removed kit-wide; the terminal agent keeps running PowerShell for project commands. Sandbox wording now says a worktree only separates the git tree and is not isolation for skipping permission prompts (loop.sh header, ORCHESTRATION guard table, SKILL.md step 6, guides). README security section got the four wording fixes from 1.1.3. CHANGELOG 2.0.0 has Upgrade notes for pwsh users. Goldens regenerated (exit-0 cases only; failing-emit error-* cases keep prior-tree goldens by design). New Windows-only suite tests/agent-kit/templates/loop-windows.sh (SKIPs elsewhere) and a non-blocking windows-latest CI job run it plus the loop harness; full suite 38/38.

Known limitations, still unverified until the Windows CI job runs: native children (claude.exe, codex.exe) may survive a slot kill under Git Bash; Git Bash may not resolve a bare LOOP_CLI to a .cmd shim, and the `.cmd` suffix workaround routes the multi-line prompt through cmd.exe, which truncates at the first newline — prefer the CLI's native .exe or node entry.

Process notes: Phase 3 needed a fourth user-approved targeted evaluation (cmd.exe prompt truncation found in attempt 3). Task 05 took 2 fix cycles, task 06 took 3 plus a user-approved extra line-patch cycle; the final audit added corrective task 07a (driver wording). Remember next time: grep for qualifier words ("bash driver", plural "drivers") in templates, not only the obvious twin terms, and check every acceptance command for shell-quoting before relying on "prints nothing".
