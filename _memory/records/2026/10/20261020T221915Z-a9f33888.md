Decision (2026-10-20, user request): CI never runs the full agent-kit suite — the repository owner is on the free GitHub Actions tier.

- `.github/workflows/agent-kit.yml` runs only `bash tests/agent-kit/run-all.sh --quick` on every trigger (pull_request, push to master, workflow_dispatch). The bash:3.2 Docker pull and the `AGENT_KIT_DOCKER=1` full-suite step were removed.
- The full suite (`bash tests/agent-kit/run-all.sh`, incl. self-install, the loop harness and pwsh twin-parity cases) and the Docker bash:3.2 emit-golden leg (`docker pull bash:3.2`, then `AGENT_KIT_DOCKER=1 bash tests/agent-kit/templates/emit-portability.sh`) run only locally — the feature workflow's rung 3 and the agent-kit release procedure (docs/agent-kit/guide/contributing.md § Version and releases, step 5) already require the full suite before a commit/release.
- This supersedes the CI part of 20261015T092948Z-271d0587 (which said the Docker bash:3.2 check runs in CI); its other content stands.
- Do not re-add full-suite or Docker steps to any workflow without the user's explicit approval.
