Pitfall: on Cursor, kit evaluator subagents cannot run commands.

The emitted Cursor evaluator agent has `readonly: true` in its frontmatter, so every shell call is refused, while its body says "Execute before you score" and treats a verdict without execution evidence as invalid. In goal memory-store-c-capture this produced infra-only NEEDS FIXES verdicts until the orchestrator logged a decision: the orchestrator runs each acceptance-criterion command itself, saves the verbatim output as an evidence file under the goal's spawns folder, and the evaluator judges that evidence plus its own code reading.

How detected: the first task evaluation returned NEEDS FIXES with failure_class infra; `.cursor/agents/evaluator.md` showed `readonly: true`.

Avoid it: until the kit resolves the conflict (either drop readonly for evaluators on Cursor or reword the execution rule for read-only harnesses), build an evidence script per task before spawning the evaluator, include the exact commands, and record the evidence-basis decision in the orchestration log.
