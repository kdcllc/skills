Pitfall: removing subshells from a bash script silently changes bytes and error behavior.

Seen while making skills/agent-kit/bin/emit.sh fork-free (goal test-suite-speed). Every one of these passed the golden suite and was only caught by evaluator code reading plus an A/B harness against the old script:

1. $(...) strips ALL trailing newlines. A replacement that reads into a variable (read -d '', printf -v) keeps them. Appending to an existing CLAUDE.md that ended in "\n\n" gained a blank line; a template ending in an empty-valued token gained "\n\n\n".
2. A heredoc feed always adds one trailing newline; < <(printf '%s' "$x") adds none. Loops that do not skip empty lines read an extra empty line (it leaked into Copilot frontmatter).
3. f "$(g)" ignores g's failure; a plain statement or assignment under set -e aborts. Removing a "; printf x" sentinel restored abort behavior at most sites but made two foreign-file hash sites abort where the old code continued. Decide per call site.
4. A function that used to run inside $(...) had its side effects (record_syntax, globals) thrown away; running it in the parent shell surfaced a new syntax error and exit 6.
5. read -r -d '' stops at the first NUL; $(cat) drops NULs and keeps reading. A UTF-16 .gitignore was truncated.
6. Checking a tool's stdout but not its exit status hid a broken pwsh (exit 1, empty output) as "no parse failures".
7. A new temp-dir dependency (mktemp -d) made emit fail under TMPDIR=/nonexistent where the old code did not.
8. Locals named like the caller's output variable (content, idx, _tmp) break printf -v under set -u.

How to avoid: save the old script, write an A/B harness that runs both on the same inputs and compares tree, stdout, stderr and rc (normalize root paths and bash's "<script>: line N:" prefix), and add a scenario for every input class: pre-existing user files (LF, CRLF, trailing blank lines, NUL bytes), unreadable files, failing or stubbed tools, bad TMPDIR, path characters like apostrophes. Turn each evaluator reproducer into a permanent scenario.
