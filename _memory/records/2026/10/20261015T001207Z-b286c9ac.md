## Decision

Persist the model circuit-breaker JSON state at `_memory/loop/breaker-state.json` (gitignored). It is never staged by loop commit guidance and never placed under `_loop/` or another CB0-protected path.

## Why

- Protected-path commit sweeps still exit 4 when `_loop/` changes, so runtime breaker state cannot live there.
- `_memory/loop/` is the kit's tracked loop-state tree, but it is not in the loop's `PROTECTED_PATHS`, which cover only `_memory/records/` and `_memory/quarantine/` plus the loop machinery. A gitignored file there survives iterations without tripping CB0.
- The previous location, `_goals/breaker-state.json`, was retired with the `_goals/` folder.

## Rejected alternatives

- A state file inside `_loop/`: blocked by CB0 semantics.
- A seeded or manifest-tracked breaker file: it is runtime-mutable and not emitted by setup.
- Tracking it in `_memory/loop/`: it would conflict across machines and change on every iteration.

## Consequences

- Emit appends `_memory/loop/breaker-state.json` to `.gitignore` on loop installs.
- The upgrade migration moves a legacy `_goals/breaker-state.json` there, untracks it, and removes the retired `_goals/breaker-state.json` ignore line by exact match.
- Both loop drivers (bash and PowerShell) read and write the new path.
