`skills/agent-kit/templates/tools/bash-launcher.cmd` keeps getting rewritten from CRLF to LF outside git (2026-10-29, and again on 2026-10-30 at 07:35). The cause is not git: `.gitattributes` has `*.cmd -text`. It is most likely an editor end-of-line or format-on-save setting.

The LF copy breaks the emit goldens and the windows-launcher checks. At the start of every session, run `git status --porcelain -- skills/agent-kit/templates/tools/bash-launcher.cmd`. If it shows changes, run `git checkout --` on it; the launcher must stay byte-equal to HEAD with 56 CRLF lines. The gitignored instance `_kit/*.cmd` copies were found LF too.
