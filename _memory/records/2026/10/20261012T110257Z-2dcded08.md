("agent-kit: finish memory-store follow-ups for 1.0.0"). It finished memory-store-a-core
follow-ups #3, #4, #5 and #9 for agent-kit 1.0.0 (no version bump).

What shipped:
- memory.sh performance: index and search no longer fork per record. At 200 records index
  went from about 5.1 s to about 0.5 s and search from about 4.8 s to under 0.15 s, with
  output byte-identical to the previous bash twin apart from the fixes below (checked under
  gawk, mawk, busybox awk, gawk --posix).
- Symlinks: both twins follow symlinks at every store level; broken links, loops and
  leaf-to-directory links are ignored silently; staleness uses the target's mtime. The pwsh
  twin no longer crashes on a broken link or unreadable record.
- Ties: pwsh tie order now matches GNU sort's whole-line fallback.
- Hardening: bash id joins compare as strings, echo-option-like tags are kept, and an
  over-long --limit prints only "memory: invalid --limit" (exit 2).
- Tests: tests/agent-kit/templates/memory.sh gained cases for every item, MEMORY_SUITES
  (bash, pwsh, parity) suite selection and a MEMORY_PERF timing check.
