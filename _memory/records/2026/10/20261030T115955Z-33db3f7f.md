When another session commits into the working branch partway through a goal, three things need handling:
- Record those commits in an exclusion list, so the Phase 5 changed-path list leaves out their paths.
- Re-add any path this goal also edits, and diff the shared files from the external commit so only this goal's hunks show.
- Re-check every criterion that pins content those commits changed.

In hook-telemetry the user's README rewrite added an `## [Unreleased]` entry. That broke a criterion that required an empty Unreleased section, and the first path-level exclusion dropped this goal's own README row from the audit.
