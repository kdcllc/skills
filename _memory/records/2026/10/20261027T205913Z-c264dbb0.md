Goal memory-prune (agent-kit 2.1.0): shipped on branch feat/memory-prune, uncommitted for review.

Outcome: new `_kit/memory.sh prune [--plan|--apply] [--goals] [--research] [--only <name>]` deletes finished gitignored scratch folders under `_memory/work/goals/<goal>/` and `_memory/work/research/<topic>/` only when the knowledge they hold is durable. A goal is judged by the record ids on its LATEST `### <ts> — …ARCHIVED:` heading (ids found by substring pattern after the last `ARCHIVED:`, so free-form and "Archive correction" lines parse); with no such heading it falls back to every record whose `source:` is exactly `goal <g> (goal.md)`. Research uses the ids on line 2 of `ingested`. Durable = record file in `HEAD` and, when a base ref resolves (first of `refs/remotes/origin/HEAD`, `origin/main`, `origin/master`), in that ref too; no remote → `HEAD` alone. Everything else is kept with a reason (`keep:missing|uncommitted|unmerged:<id>`, `keep:no-git|symlink|tracked|no-log|no-ids|not-archived`); `--only` values are exact names never used to build paths; never follows symlinks; exit 0/2/4. The feature skill's Phase 2 runs `prune --apply` once immediately before Recall (before the new goal folder exists), never blocks, and logs the summary once the folder exists. Spec lives in the shipped `_memory/README.md` (`### prune`); memory-protocol `## Prune`, ORCHESTRATION, harness matrix, CHANGELOG 2.1.0 describe it; new guard `tests/agent-kit/templates/memory-prune.sh` (41 checks) plus out-of-suite mutation proofs. Full suite 39/39.

Key decisions: durability includes the remote default branch (see the decision record); delete outright, no trash; research workflow does not prune; memory-capture loses goal-folder tag hints for pruned goals (accepted, documented).
