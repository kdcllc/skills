Goal agent-kit-align-docs-working-tree — shipped as agent-kit 1.1.1 (PATCH; both CHANGELOG entries under Fixed).

Outcome: the align-docs skill template now discovers the Phase 6 change set from the merge base to the working tree (git merge-base, git diff --stat / --name-only --no-renames, git ls-files --others --exclude-standard, run from the repo root). Paths outside every task's writes: set — tracked and untracked alike — are listed as "changed, not owned by this goal" and excluded; standalone runs or goals without writes: sets confirm candidate paths with the user (non-interactive runs escalate). Phase 6.4 per-doc and 6.5 final scope checks diff against a git tree-object snapshot taken before doc edits. The research skill's Phase 4 handoff now path-Reads {{IDE_DIR}}/skills/feature/SKILL.md and continues at its Phase 3; its intro line no longer says "feeds feature Phase 4". New guard tests/agent-kit/templates/phase-handoffs.sh locks both; emit goldens regenerated; maintainer guides and contributing.md guard table updated.

Why: interactive /feature never commits implementation, so the old `git diff --stat <base>...HEAD` discovery saw nothing and the old "git status shows only documentation files changed" audit failed on every feature.

Remember next time: the versioning table makes any Upgrade notes entry MAJOR and a backwards-compatible Changed entry MINOR — a patch release can only carry Fixed/Security entries; generic emitter behavior (blocked on hand-edited files, --force) is already documented in 1.0.0 and does not need a per-release upgrade note.
