## What went wrong

In goal fix-cycle-provenance, task 01 required every late `[new]` required-fix item to carry `missed earlier: <reason>` text but did not say where in the item it goes. Task 02 extended the continuation ladder's unanimity and repeated-failure-signature comparisons to strip trailing provenance tags. Nothing stripped the justification text.

An item listed as `X — missed earlier: r [line-patch] [new]` in one cycle and `X [line-patch] [carried]` in the next therefore no longer normalized to the same item. The repeated-signature hard guard silently stopped firing for exactly the case the goal created.

## How it was detected

The task-02 evaluator listed the gap as a minor note, because no task requirement covered it. The Phase 5 final audit re-judged it as major, since it was a regression in a hard guard at a seam between two tasks, and returned ISSUES. The same audit promoted a second carried minor note (a tag-check round trip that could delay a bypass escalation). Both needed corrective tasks, an additive amendment, and a targeted evaluation that took three attempts.

## How to avoid it

- When a goal adds any text to items that feed an identity or signature comparison (tags, justifications, annotations), fix that text's exact position in the item format in the contract task. Make stripping it a requirement at every comparison site in the same plan, not as a follow-up.
- In the final-audit package, list every minor note carried from task evaluations and ask the auditor to judge each one at goal level. Seam defects tend to be filed as minor at task level.
