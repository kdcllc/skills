Open follow-ups after goal memory-work-layout (agent-kit layout: `_goals/` and `_research/` retired; everything under `_memory/`), unreleased. None blocks the change; the final audit was APPROVED with notes.

1. **Fixture-root guard on the remaining suites.** The guard (`tests/agent-kit/lib/fixture-root.sh`) is not yet used by `emit-golden.sh`, `emit-portability.sh`, `memory-capture.sh`, `lib/memory-release-c.sh` and `lib/emit-cache.sh`. Several of them still `cd "$REPO_ROOT"` and run emit or `git -C` on fixture roots. The orchestrator scoped this out because emit now rejects an empty `--root`. These suites should still adopt the guard.
2. **Seed comments after upgrade.** Upgraded installs keep their old `_memory/loop/backlog.md` comments, because seeds are never rewritten, so a comment may still name `_goals/ESCALATIONS.md`. The CHANGELOG upgrade notes mention this. A one-time comment rewrite could be considered.
3. **Feature SKILL template headroom.** The template is at 11236 of the 11264 bytes `skill-slimming.sh` allows, so the next edit must trim first.
4. **`emit-migrate.sh` runtime.** It takes about 7 minutes, because it runs many full emits. It could share fixture emits or cache emit output.
5. **Docs left as history.** `docs/agent-kit/research-*.md` and `design-parallel-dispatch.md` were deliberately left unchanged and still describe the old `_goals/` / `_research/` layout.
6. **Process.** The shell tool can launch a command twice. Evaluator context and evidence must be written before the spawn, in a separate turn. Long suites should run behind `mkdir` locks with a private TMPDIR.
