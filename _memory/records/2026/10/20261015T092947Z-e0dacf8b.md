Goal test-suite-speed closed 2026-10-15 on migrate/agent-kit (local commit, no PR, no push). Outcome: shipped.

Problem: bash tests/agent-kit/run-all.sh took 7m58s (wall 465 s). Root cause was skills/agent-kit/bin/emit.sh at about 12 s per self-answers emit: 3827 forks and 1277 execs per run from $(...) captures, printf|awk pipelines, per-file pwsh and sha256 calls, and repeated whole-text passes per template and per harness. emit-migrate.sh made ~36 of those runs sequentially (411 s), and emit-portability.sh ran a Docker bash:3.2 leg with a network apk add on every local run.

What shipped:
- emit.sh: median 11.2 s → 2.4 s per self-answers emit, forks 3827 → 471, execve 1277 → 193. Fork-free Bash 3.2 *_into helpers, a per-run template cache, marker fast paths, single-pass token scan, one pwsh process for all .ps1 checks, batched sha256. Output byte-identical to the previous emitter (one accepted fix: an apostrophe in --root no longer reports false .ps1 parse failures).
- emit-migrate.sh: parallel blocks via lib/parallel.sh plus one shared canonical emit for seven identical-input mutation checks; 411 s → ~23 s, same 39 labels.
- Docker bash:3.2 check opt-in (AGENT_KIT_DOCKER=1; FAIL when requested but unavailable); CI pulls the image and sets the opt-in.
- New tests/agent-kit/templates/emit-perf.sh: structural guards with content-anchored mutation proofs; EMIT_PERF=1 timing and strace fork budget.
- run-all wall 465 s → 123 s (real 7m58s → 2m06s). The floor is now memory.sh [parity] at ~123 s (pwsh twin per step), out of scope here.

Remember next time:
- Byte identity for a bash refactor needs an A/B harness against a saved copy of the old script, not just goldens. Goldens only emit into fresh roots with pwsh stripped; the bugs evaluators found lived in pre-existing files, CRLF/NUL input, failing tools, unreadable files and error exits.
- Read-only evaluators need orchestrator-run evidence scripts per task; keep them under the goal's evidence/ folder and re-run after every fix cycle.
- Next speed lever: make memory.sh pwsh/parity legs opt-in locally, or cut their per-step pwsh startup.
