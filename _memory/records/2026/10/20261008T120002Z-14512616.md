## Decision

Both emit twins **warn** (stderr line, counted in `warnings W`, exit 0) when `frontier_alt_family` equals `frontier` without `arbiter_same_family: true`, or equals `alt_family` (even with the flag—map rule: never reuse light alternate for arbitration). Both twins **exit 3** when any `loop_chain` entry is `best`, `fable`, or starts with `claude-fable`.

## Why

Same-ID arbiters violated the model map’s intent but should not block `--upgrade` on existing installs; usage-credit model names in unattended loops are a cost and reliability hazard worth blocking.

## Rejected alternatives

- Hard error on all arbiter equality cases (would break upgrades silently).
- Staleness warnings keyed on current date (breaks emit determinism).

## Consequences

Upgrades from v0.28.0 with equal alt/arbiter pairs succeed with warnings. Denylist lives in one named constant per emit twin. Loop drivers inherit validated chains only after emit passes.
