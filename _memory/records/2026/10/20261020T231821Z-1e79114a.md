## Question

What should change in agent-kit's optional autonomous loop (bash driver, backlog, slots, breakers, integrator) to bound unattended runs, improve retries, resist test gaming, and make runs reviewable? Can harness-native features replace parts of the driver?

## Load-bearing findings

- Every surveyed unattended system (SWE-agent, OpenHands, Claude Code headless, Copilot cloud agent, Ralph plugin) enforces hard caps on cost, turns or time. The kit's loop is bounded only by max-iterations: no per-iteration wall clock, and parsed usage is never acted on.
- Retry gains come from grounded, high-quality feedback, not retry count (Reflexion: ungrounded reflection 52% vs 60% baseline; Olausson et al. ICLR 2024: stronger-model feedback beats self-feedback at every budget). Attempt 2 currently sees only one-line LEARNINGS.
- Prompt rules do not stop test gaming (ImpossibleBench: GPT-5 cheated 54% on Conflicting-SWEbench under strict prompt). Deterministic diff checks plus human-owned acceptance tests are needed, layered.
- Specification defects are the largest multi-agent failure class (MAST 41.77%), motivating a backlog readiness linter.
- No harness-native loop offers disjoint-write admission, quarantine or protected paths; keep bash as the portable core.

## Ingestion corrections (verified against code and local probes)

- The driver cannot see evaluator verdicts: the evaluator runs inside the slot, the outbox is rm -rf'd after reap, goal scratch vanishes with the worktree. A retry dossier needs a new pinned outbox file plus a persisted attempt store (effort M).
- Cursor usage fields conflict: report cites docs with none; harness-matrix live probe (2026-09-03) saw camelCase usage. Re-probe; budgets must fail open.
- claude --bare (2.1.296) skips CLAUDE.md discovery and never reads OAuth/keychain, so opt-in only. --max-turns absent from 2.1.296 help.
- Cross-family evaluator cannot be a driver check (driver can't see subagent models; Claude Code pins are Anthropic-only).
- Unverified load-bearing risks: Claude Code >= 2.1.302 may default -p to Manual permission mode; codex exec may default to read-only sandbox, breaking the documented LOOP_CLI recipe.

## Candidate ranking (not yet adopted)

1. Driver budgets and per-iteration timeout. 2. Gitignored JSONL run ledger and end-of-run summary. 3. Runner-free test-tamper diff check. 4. Attempt dossier. 5. Structured Claude rate-limit parsing with upward breaker recovery. Hygiene: explicit permission mode and sandbox in LOOP_CLI recipes; backlog linter.

## Rejected

Harness-native replacement of dispatch (loses admission, quarantine, portability). --bare as default. Driver-level cross-family evaluator check.

## Unchanged decisions

Driver-owned dispatch, disjoint writes admission, best-of-N rejection, bash single source. The earlier "budgets unenforceable" decision concerned markdown policy; driver enforcement from parsed CLI usage is consistent with it.
