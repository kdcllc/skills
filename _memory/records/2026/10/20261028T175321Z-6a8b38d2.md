Decision (goal agent-kit-opt-in, agent-kit 2.2.0): edit-blocking hooks for kit-owned files are written only into harness configs that emit itself creates, and they fail open everywhere except an explicit deny.

Decision details:
- With flags.kit_guard true, emit writes .claude/settings.json (PreToolUse, matcher Edit|Write|MultiEdit|NotebookEdit, command bash "$CLAUDE_PROJECT_DIR/_kit/kit-guard.sh" hook claude) and .cursor/hooks.json (preToolUse, matcher Write|Delete, command bash _kit/kit-guard.sh hook cursor) only when the file is absent. An existing file is left untouched and emit prints one warning containing the exact snippet to merge. Turning the flag off never deletes those files (they are user-owned, kept as foreign manifest entries); emit warns while they still reference _kit/kit-guard.sh.
- Copilot and Codex get no hook (Copilot agent hooks were Preview; Codex has none used) — a partial-support warning, plus emit.sh --check / _kit/kit-guard.sh check for CI and the orchestration gate.
- The guard denies with exit 2 (plus Cursor deny JSON), prints {"permission":"allow"} on every Cursor allow path (Cursor blocks an exit-0 reply that is not valid JSON), and fails open on malformed input or a missing manifest.

Alternatives considered: JSON-merging into existing configs (rejected: emit has no safe JSON merge and the files are user-owned); a kit-installed hook for every harness (rejected for Copilot/Codex); fail-closed hooks via Cursor's failClosed (rejected: a fresh clone has no _kit/ because it is gitignored).

Consequences:
- Every existing claude-code install already has .claude/settings.json (emitted for the spawn-depth env), so adopting the guard on an upgrade means merging the snippet by hand.
- On a fresh clone or CI checkout the hook command points at a missing script and exits 127: Claude Code shows a non-blocking hook error, Cursor fails open (non-2 exit codes proceed unless failClosed, per cursor.com/docs/agent/hooks, checked 2026-10-28). The guard is inactive until emit runs; check skips _kit/* entries with a note.
- Dual-harness installs may run the guard twice (Cursor also loads Claude Code hooks); hook claude detects a Cursor caller and answers in Cursor's format.
