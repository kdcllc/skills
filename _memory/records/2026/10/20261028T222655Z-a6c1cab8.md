Decision (goal evaluator-gate-hardening, user-chosen in Phase 1): late findings on re-evaluation are restricted, and blocking requires a citation. This refines the earlier provenance decision, under which any late [new] item could block with a "missed earlier" reason.

What was decided:
- Citation rule. In Phase 4 task evaluations, ladder re-evaluations and Phase 5 audits, every blocker or major cites exactly one of AC<n> (audits: TT/AC<n>), SC<n> or a floor item F1-F7. An uncited finding of any severity cannot block; it is a [backlog] note under Notes (non-blocking). Phase 3, Phase 6 and arbitration keep today's uncited shapes and still block on blockers.
- Late-finding rule. On a re-evaluation, a [new] required fix stays blocking only when:
  - its location is in the package's "Changed since last evaluation" list (from eval-tree snapshots);
  - it cites F1, F3, F4, F7 or any AC<n>;
  - or it is a reversal, which keeps its criteria-defect routing.

  Every other late finding is demoted to [backlog] [late] and still counts toward the drift trigger. A red rung-1 or rung-2 check always blocks through the PASS definition.
- The orchestrator checks citations and late-finding scope in the same tag round trip, which consumes no cycle. It appends backlog notes to follow-ups.md and logs issue keys. Keys never change a verdict. Only ladder: auto early entry routes on a repeated [structural] key.

Alternatives considered:
- Banning late findings outright. Rejected, because it would hide real defects.
- Blocking only on findings in changed files. Rejected, because an unmet criterion or weakened test must always block (F3/F4).
- Having keys drive escalate-mode decisions. Rejected; keys are log-only there, by user choice.

Consequences:
- Evaluators must cite. The calibration exemplar in evaluator.md now cites AC1.
- Re-evaluation packages carry the changed list, and the orchestrator snapshots the tree at every evaluator spawn.
- Backlog rows reach the PR body ("Backlog (not fixed here)"), or the Phase 5 report when Phase 7 is skipped.
- A gap remains: an unmet requirement that no AC or SC covers has no direct citation. F5 (a contradicted completion claim) fits in practice.
