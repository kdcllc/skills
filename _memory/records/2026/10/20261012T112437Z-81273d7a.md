External research (2026-10-12) on whether the kit's Bash + PowerShell twin scripts should become one Node/TypeScript or Python implementation. Finding: no port. No harness install path (Claude Code native/brew/winget/apt, Codex Rust binary, Cursor CLI script, VS Code) guarantees `node` or `python3` on PATH; Windows `python3` is an App Execution Alias stub and macOS `python3` is an xcode-select shim. Compiled binaries (Bun 57-114 MB) exceed `npx skills add` direct-download limits and add signing.

The PowerShell twins (`loop.ps1`, `memory.ps1`, `emit.ps1`) all `#Requires -Version 7`, but fresh Windows ships only Windows PowerShell 5.1, which is what Claude Code and reportedly VS Code Copilot fall back to. Claude Code uses Git Bash for its own Bash tool on Windows. Recommendation: Bash as single source of truth behind a 5.1-compatible Windows launcher that locates Git Bash; retire `.ps1` twins group by group (ledger, memory, loop + breaker, emitter last) after adding macOS/Windows CI legs, golden-file emitter tests and exit-code characterization tests.

Ingest review found `emit.sh` requires Bash 4+ (`declare -A`) and jq, so neither emitter runs on stock macOS (Bash 3.2, no pwsh); loop/breaker/memory/log-spawn are already Bash-3.2-safe and jq-optional. Unverified: Git Bash killing native Windows grandchildren, and resolving `cursor-agent.cmd`. Durable copy: docs/agent-kit/research-runtime-language.md.
