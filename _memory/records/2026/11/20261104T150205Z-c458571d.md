Pitfall: `claude -p --output-format json` returns only the agent's last assistant message in `.result`.

What happened (goal release-240-priority, task 02): a headless test-writer ran a background job plus a polling loop and then wrote its full report. A late task notification produced one more short message ("That notification is from my own wait loop…"). That message became `.result`, so the saved spawn report was 474 bytes and the real report was lost from the spawn file.

How detected: the report was tiny next to the work done, and it said "the report above stands as written".

How to handle it: check report size after every headless spawn. Recover the full text from the session transcript at `~/.claude/projects/<project>/<session-id>.jsonl`, selecting assistant text blocks with jq, for example `select(.type=="assistant") | .message.content[] | select(.type=="text") | .text`. In worker packages, require foreground commands only and say the final message must be the complete report. Separately: the orchestrator's dispatch command was re-invoked by the tool three times in two goals. log-spawn's duplicate guard stopped every second run, but plain `>>` appends weren't guarded, so make every orchestrator side effect idempotent.
