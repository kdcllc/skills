Pitfall: ripgrep skips hidden directories, so searches over the emit-golden corpus silently miss the .cursor/ and .github/ goldens.

What happened (goal resume-routing-followups, task 03): an acceptance criterion counted feature descriptions with `rg '^description: …' -g '*.golden' tests/agent-kit/fixtures/emit-golden` and saw only .claude goldens; without --hidden, rg ignores every dot-directory. The same command also counted error-* cases, whose goldens are pre-existing install snapshots that emit refuses to rewrite, so the old wording there is correct.

How detected: the count was far below the number of cases × harnesses.

Avoid it: add `--hidden` to rg (or use grep -r) for anything under tests/agent-kit/fixtures/emit-golden, exclude `cases/error-*` and `.prior` inputs when checking emitter output, and re-run consumer searches with --hidden to confirm no tracked dot-directory hit was missed.
