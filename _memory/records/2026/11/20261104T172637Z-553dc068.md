Goal release-240-git-isolation (agent-kit 2.4.0 release prep). Outcome: three local commits on feat/agent-kit-loop-follow-ups: fixture helpers, guard suite, release docs. No push, PR or tag; the version stays 2.4.0.

Root cause of the `user.email = t@t` block in the shared `.git/config` (2026-11-03): a subagent simulated merges with `git worktree add --detach $T HEAD; cd $T; git config user.email t@t; git config user.name t`. A linked worktree shares the main repository's config, so the write landed in the real repo, and 16 commits were then made as `t <t@t>`. The test suites were cleared as the source. Reproduced on throwaway clones (goal evidence repro.sh), an exported `GIT_DIR`, `GIT_DIR`+`GIT_WORK_TREE` or legacy `GIT_CONFIG` does make memory-prune write a caller's config. But it always ends with `mempr@test.local` (later fixtures overwrite case 11c's `t@t`), and `GIT_DIR` also adds stray commits.

What shipped:
- `tests/agent-kit/lib/fixture-root.sh`, on source: unsets GIT_DIR, GIT_WORK_TREE, GIT_INDEX_FILE, GIT_OBJECT_DIRECTORY, GIT_ALTERNATE_OBJECT_DIRECTORIES, GIT_COMMON_DIR, GIT_CONFIG, GIT_CONFIG_PARAMETERS and GIT_CONFIG_COUNT; sets GIT_CONFIG_NOSYSTEM=1 and GIT_CONFIG_GLOBAL=/dev/null; exports the identity `agent-kit-fixture <fixture@agent-kit.invalid>` through GIT_AUTHOR_*/GIT_COMMITTER_*.
- New `assert_fixture_repo <root>`: `--show-toplevel` must be the root and `--absolute-git-dir` must be `<root>/.git`. It rejects a failed init inside another repo, a subdirectory and a linked worktree. Every fixture helper in 14 suites runs it after `git init`, and a failure stops the suite. Fixtures no longer write `git config user.*`.
- New guard `tests/agent-kit/templates/git-isolation.sh`, 15 checks in about 20 s, with base-tree and mutation regression proofs.
- CHANGELOG 2.4.0: dated 2026-11-04, accurate terminal wording, merged overlapping bullets, a full upgrade-refresh list (including the Codex config.toml that is never rewritten and the backlog seed). Contributor guide: progress-line.sh has 18 cases, plus a git-isolation row and suite-author git rules. The loop skill and breaker.sh say 2.2.x and 2.3.x.

Remember next time: evaluators caught a fix that stopped only a subshell (loop-harness `( … ) || exit 1` was missing) and a top-level `|| return 1`, which bash ignores outside a function. Check that a failing guard actually stops the caller, not just the helper. A static init-site regex must also match wrapper calls such as `git_fixture … init`.
