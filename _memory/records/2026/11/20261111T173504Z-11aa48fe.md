Pitfall: a test that runs a copy of its own suite needs a recursion stop. In tests/orchestration-advisor/run.sh the case summary/interrupted-run-leaves-no-scratch-folder copies the suite, injects "exit 1" after a chmod 000, and runs the copy. If the injected stop were not reached, the copy would run the same case and nest without end. The plan evaluator caught this before implementation.

How to apply. Set a marker variable as a prefix assignment on the nested command only (here ORCHESTRATION_ADVISOR_NESTED=1) and return at once from the case when it is set; assert that the copy really aborted (non-zero exit and the ABORTED line); give the copy its own TMPDIR and restore owner access (chmod -R u+rwx) on it before reporting so the scratch root can always be removed.
