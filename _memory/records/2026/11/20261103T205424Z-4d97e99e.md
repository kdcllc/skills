Goal memory-prune-followups (backlog STORY-005 + STORY-011, agent-kit after 2.3.0): shipped on branch fix/memory-prune-followups, unreleased.

Outcome:
- STORY-005: `tests/agent-kit/templates/memory-wiring.sh` now creates a private `mwtmp.XXXXXX` TMPDIR under the outer `${TMPDIR:-/tmp}` before any other temp path, exports it, and removes it last in the EXIT trap. The `(leak)` and `(leak)-mutation` checks count `memory-wiring.*` only there, so concurrent runs (other sessions or worktrees) no longer drift the count. Check count unchanged (ok=32). A deterministic repro: plant `memory-wiring.foreign` in the outer TMPDIR three seconds into a run; before the fix that gave `before=0 after=1` and FAIL, after the fix it passes.
- STORY-011: `memory.sh prune` keeps a goal folder whose `progress.md` status is not `done`, printing `keep:progress:<status>` (decision step 4, after `keep:tracked`, before `keep:no-log`). The memory protocol, guide `feature-workflow.md` and `memory.md` now say Prune, then the unfinished-goal offer, then Recall. `memory-prune.sh` cases 18–22 guard it.

Key decisions: see the decision record on the keep rule. STORY-011 was split into an implementer task and a test-writer task because goal-criteria requires a dedicated test task; still one commit per story.
