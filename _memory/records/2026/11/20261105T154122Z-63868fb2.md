Pitfall: orchestrator evidence summaries that report "all rc=0" from wrapper scripts can hide failing sub-checks.

What went wrong: in goal agent-composer the Phase 5 evidence run (checks/audit.sh) reported every acceptance script with rc=0, and the orchestrator summarized it as green. Inside checks/t08c2.sh the no-PyYAML sub-run printed rc=1 (one FAIL) because a newly added test case lacked the PyYAML skip guard — the wrapper's exit code only meant the script finished.

How it was detected: the final-audit evaluator read the per-script output file and cited the regression (F2, re-audit #95); one line-patch fixed it.

How to avoid it: evidence scripts must print FAIL lines by name and turn a failing sub-check into a non-zero exit (or an explicit RESULT: FAILED line); summaries must quote per-criterion outcomes, not script rc; re-run the PyYAML-missing probe whenever tests are added to tests/agent-composer/run.sh.
