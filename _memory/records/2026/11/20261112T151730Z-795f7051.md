Planning pitfall seen in goal backlog-clear (three Phase 3 rejections): fence and consumer checks that look right but cannot see the violation. (1) rg skips dot-directories, so searches over a CI change must pass --hidden or they never look in .github/. (2) git diff HEAD and git diff --stat do not show untracked files; use git status --porcelain --untracked-files=all for new files, and a sha256 baseline for files that are already modified or untracked when the task starts. (3) A "nothing else changed" check must exclude the task's own write set (for example git diff HEAD -- . ':(exclude)tests' | sha256sum), or it fails on correct work. (4) A goal that edits .github/workflows needs trace: blind. Record a true negative and a true positive for every such check during pre-flight; the missing true negative is what let (3) through.
