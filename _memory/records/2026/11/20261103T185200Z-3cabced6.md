Goal regression-proof-resume (agent-kit 2.3.0), outcome: shipped on branch feat/agent-kit-2.3.0-regression-proof-resume, stacked on the unmerged 2.2.1 release (7417bde).

What shipped:
- Regression proofs for guarding tests. The test-ladder skill has a single-home `## Regression proof` section: a guarding test (one added to guard a fix or a behavior change) must be shown to fail on a scratch copy with one behavior-relevant edit, then pass on the real tree. The section defines the proof record fields, vacuous proofs, and seven proof-quality rules. The test-writer and implementer agents must prove guarding tests and report a `### Regression proofs` section. task-criteria section 4 caps a task at NEEDS FIXES (F3) for a missing, vacuous or unreproducible proof, even at eval_depth light. The evaluator re-runs at least one proof, or uses terminal output when it is read-only.
- Resume checkpoint. Every install (kit guard on or off) keeps per-goal state in `_memory/work/goals/<goal>/progress.md`, which the orchestrator rewrites from the feature skill's `templates/progress.md` after each phase, verdict and user decision. The header has `updated:`, `status:` and `phase:` lines, followed by the sections Next step, Git, Tasks, In flight, Waiting on user, Deviations and exclusions, and the Orchestration Progress checklist. ORCHESTRATION.md never holds progress. `reference/resume.md` defines the Phase 2 offer for unfinished goals (never automatic), a ledger cross-check, and a repository check (fetch, branch, HEAD at this write, base ancestry, merged PRs including squash merges, dirty tree). Any mismatch stops the resume. The loop is out of scope.
- Release 2.3.0: version bump, changelog section, install pins, and goldens regenerated at kit 2.3.0. A new suite, tests/agent-kit/templates/regression-proof-resume.sh (cases a–k), pins every change. kit-guard check (n) now asserts the unconditional progress line.

Process: 8 tasks (01–06 plus corrective tasks 06a/06b for the QA fixes and the release bump). A material goal amendment got a fresh Phase 3. The final audit was APPROVED, run-all passed 47/47, and QA passed 4/5.
