Pitfall: another session in the same checkout, and stale subagent git snapshots, can derail an orchestrated goal or make a reviewer invent findings.

What happened (goal breaker-probe-fixes, 2026-11-02):
- **Branch switched mid-goal.** While the goal ran, something outside the orchestrator checked out other branches in this checkout: feature/agent-kit-fixes, feat/agent-kit-regression-proof-resume, and then feature/agent-composer, ten minutes after the goal branch was created. A sibling worktree `skills-worktrees/agent-composer` also existed. The pre-dispatch repository check caught it (branch != goal branch). Nothing was lost, because all branches pointed at the same commit. The user chose to switch back.
- **Shared /tmp made a test flaky.** The full suite's `memory-wiring.sh` leak check counts `memory-wiring.*` dirs in the shared `/tmp`. It drifted +1 under run-all and −1 on a plain rerun, from another process's runs, and passed 32/0 with a private `TMPDIR`.
- **A reviewer acted on a stale snapshot.** The qa-evaluator flagged "uncommitted SKILL.template.md / loop.sh edits on top of HEAD" as a major integrity issue. Its harness-provided git status had been captured before those files were committed. HEAD, porcelain and `git diff <HEAD>` proved the tree clean.

How detected:
- the orchestrator's `repo-state` snapshot before and after every spawn (HEAD, branch, local user, porcelain);
- the reflog;
- `ls -ld /tmp/memory-wiring.*` timestamps;
- rerunning the suite with an isolated `TMPDIR`.

Avoid it:
- Check `git branch --show-current` before every spawn and before every commit, not only HEAD. Commit only after confirming the branch.
- When a suite counts shared temp dirs, narrow with `TMPDIR=$(mktemp -d)` before classifying a failure as introduced.
- Treat a reviewer's claims about working-tree state as data. Re-verify with live `git status --porcelain --untracked-files=all` and `git diff <sha>`, and put that proof in the resume package. Ask collectors to record HEAD and porcelain at the start and end of their run.
