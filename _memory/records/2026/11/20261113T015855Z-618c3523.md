When a test harness launches the claude CLI from inside a Claude Code session, strip the session's own variables with an explicit denylist, not a CLAUDE_CODE_* prefix rule with a keep-list. The CLI binary reads many CLAUDE_CODE_* auth, TLS, proxy and provider variables (CLAUDE_CODE_CLIENT_CERT, CLAUDE_CODE_SKIP_*_AUTH, CLAUDE_CODE_HTTPS_PROXY, CLAUDE_CODE_OAUTH_TOKEN, CLAUDE_CODE_USE_*); a keep-list that goes stale silently breaks authentication, while a missed session variable only leaks. tests/agent-kit/evals/run.sh removes 18 names (the 17 a session exported on 2026-11-13 plus CLAUDE_CODE_SSE_PORT); refresh with `env | grep -E '^CLAUDE' | cut -d= -f1` inside a session.
