## What went wrong

tests/agent-kit/templates/invocation-flags.sh's own header recommends a regression-proof method that copies only skills/agent-kit/, tests/agent-kit/templates/ and docs/ into a temp dir and runs the copied script. That partial copy always fails section 15 (the research-doc status check reads _memory/research/token-efficient-skills.md, which is not copied), so "the mutated copy exits 1" holds whether or not the mutation is detected. A regression proof built that way cannot fail.

## How it was detected

The Phase 3 goal evaluator ran the unmutated partial copy and got exit 1 with an unrelated FAIL. A first fix using `git ls-files -z | xargs -0 tar -cf -` also broke (xargs split the tar call and it died on SIGPIPE, so the copied script did not exist, exit 127).

## How to avoid it

Copy the whole working tree without .git: `c=$(mktemp -d); git ls-files -co --exclude-standard -z | tar --null -T - -cf - | tar -xf - -C "$c"`. Always run an unmutated-copy control that must exit 0, and require that the mutation produces exactly the expected number of `FAIL:` lines (`grep -c '^FAIL:'` on stderr) so only the target assertion fails.
