Pitfall: wontfix reasons written from memory were false. In goal backlog-sweep the orchestrator closed nine follow-up rows as wontfix with one-line reasons. The final audit, asked to check each reason against the tree, found three false or unsupported: one claimed scripts/validate-skills.sh rejects a symlinked SKILL.md (it uses a test that follows links), one cited a reviewer instruction the example file does not contain, one claimed the docs tell callers to read the message.

How to apply. Before closing a follow-up row as wontfix, verify the reason with a command or a file read, the same as any other claim that goes into a pull request. Put "check each fixed and wontfix row of follow-ups.md for truth" in the final audit package; it cost one cheap re-audit and caught all three.
