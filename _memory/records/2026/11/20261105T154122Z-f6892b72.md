Pitfall: an editor save that converts skills/agent-kit/templates/tools/bash-launcher.cmd (or any agent-kit .cmd template) from CRLF to LF breaks the agent-kit suites even though git diff --ignore-cr-at-eol is empty.

What went wrong: during goal agent-composer the launcher template was rewritten with LF endings in the working tree (no content change). bash tests/agent-kit/run-all.sh self-installs first, copying it into _kit/*.cmd, so emit-golden (_kit/log-spawn.cmd mismatch) and windows-launcher (LAUNCHER_CMD not all-CRLF) failed — suites that had passed hours earlier.

How it was detected: Quality Checks failure narrowed by hashing the working tree before each spawn (tools/safety.sh snapshots showed the file changed between two spawns that never wrote it) and `file` reporting no CRLF.

How to avoid it: classify as local-edits and restore with git checkout -- <file> (user-approved); keep .cmd templates CRLF (editor setting / .gitattributes); check `git status -- skills/agent-kit` before blaming the goal for agent-kit suite failures.
