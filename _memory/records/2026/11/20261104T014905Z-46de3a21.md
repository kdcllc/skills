What went wrong: two planned acceptance criteria could not do their job. (1) A check meant to find "Codex-only … Workflow State Tracking" in prose used `grep -o 'Codex-only[^.]*Workflow State Tracking'`; the required caveat names `templates/progress.md` and `reference/resume.md`, and `[^.]*` stops at the first dot, so a correct implementation could never pass. (2) An awk range `/^\*\*When\.\*\*/` meant for the memory protocol's Prune section matched the Recall section's `**When.**` first, so the check printed 0 on the old text instead of firing.

How it was detected: (2) by pre-flight, because the true-positive run on the current tree gave the passing value; (1) by the Phase 3 goal evaluator, which built a requirement-shaped scratch sample.

How to avoid it: for prose spanning file names, join lines with `tr '\n' ' '` and use a bounded window such as `grep -oE 'A.{0,300}B'`, not `[^.]*`; scope awk ranges to the section heading first (`/^## Prune/{p=1} p&&/^\*\*When/`); always record both a true positive on the current tree and a true negative on a scratch copy with the edit simulated.
